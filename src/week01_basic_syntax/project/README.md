## TIP CACULATOR
A project developed by me in my first week studying Java


## About the project
A tip calculator which gets the bill value and calculates the percentage of the tip and the payment for each client who is going to pay it.



##### The program calculates:
- Tip value.
- Bill final value.
- Payment value for each person.


## Technologies used
- Java
- Scanner
- Math function
- Printf


## Objective
Practice concepts I learned during the week.
